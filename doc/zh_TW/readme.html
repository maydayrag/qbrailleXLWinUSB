QBraille XL WinUSB 點字顯示器驅動程式

本附加元件讓 NVDA 2026.1 以上版本透過 Microsoft WinUSB 連接 HIMS QBraille XL，以及使用相同通訊協定的 Braille EDGE 點字顯示器。

功能

  • 自動偵測 USB VID 045E、PID 930B 的相容裝置。
  • 支援由 Zadig 安裝的 Microsoft WinUSB 驅動程式。
  • 支援點字輸出、游標定位鍵、點字鍵盤及裝置功能鍵。
  • 與 NVDA 2026.1 及 2026.2 相容。

安裝與使用

  1. 使用 Zadig 將 QBraille XL 的 USB 驅動程式設為 WinUSB。
  2. 安裝本 NVDA 附加元件並完整重新啟動 NVDA。
  3. 將 QBraille XL 切換至 USB 模式並連接電腦。
  4. NVDA 應會自動偵測顯示器。也可在「NVDA 設定」的「點字」類別中選擇「QBraille XL (WinUSB)」。

疑難排解

若未偵測到裝置，請確認 Windows 裝置管理員中的裝置使用 WinUSB，而且硬體識別碼包含 VID_045E&PID_930B。更新附加元件後，請務必完整重新啟動 NVDA，以釋放舊版驅動程式持有的 USB handle。

若問題仍然存在，請將 NVDA 日誌等級設為「偵錯」，重新連接裝置，並附上包含 qbrailleXLWinUSB 的完整日誌。
