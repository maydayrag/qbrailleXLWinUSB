QBraille XL / Braille EDGE 點字顯示器驅動程式 2.0

讓 NVDA 2026.1 至 2026.2透過 USB WinUSB 或藍牙序列埠（SPP）連接 HIMS QBraille XL 或相容的 Braille EDGE 點字顯示器。

相容 NVDA 2026.1～2026.2。NVDA 2026.3 已內建點字顯示器驅動程式，不需安裝本附加元件。

功能

  • 自動偵測 QBraille XL / Braille EDGE。
  • 自動偵測 Braille EDGE／BrailleEDGE 藍牙 SPP 裝置，不必手動選 COM 埠。

安裝與自動偵測

  1. 安裝本附加元件並完整重新啟動 NVDA。
  2. 開啟「NVDA 設定 → 點字 → 變更顯示器」，選擇「自動」。若有設定自動偵測裝置範圍，請包含「QBraille XL / Braille EDGE 點字顯示器驅動程式」。
  3. 依下列方式完成 USB 或藍牙連線。NVDA 在背景偵測到裝置並收到回應後會啟用驅動。也可以手動選擇上述驅動，連接埠選「自動」，嘗試目前可用的連線。

藍牙連線

  1. 在 QBraille XL 的 Connectivity（連線）選單選擇 Bluetooth Braille（藍牙點字）進入配對模式；已配對時，選擇這台電腦的點字連線。
  2. 在 Windows 藍牙設定配對「Braille EDGE」。若要求 PIN，原廠手冊指定為 0000。
  3. 確認 Windows 已建立藍牙序列埠（SPP／COM），並保持裝置開機、可連線。NVDA 會自動開啟對應埠。

原廠將「Braille EDGE」用於點字 SPP，「QBrailleXL」用於另一個鍵盤 HID 連線。只配對鍵盤無法提供點字輸出。藍牙不需要 Zadig；若要使用混合鍵盤模式，需另外配對鍵盤。

USB 連線

  1. 使用 Zadig 為 QBraille XL USB 裝置安裝 Microsoft WinUSB。
  2. 將裝置切換至 USB 模式並接上電腦。

2.0 啟動延遲修正

  • 啟動偵測先嘗試已接上的 USB，不再讓藍牙埠列舉擋住 USB 連線。
  • 先查已知的原廠 WinUSB 介面，成功後不再列舉登錄檔與其他介面。
  • 裝置已回應時直接啟用，不再進入讀取等待。
  • 保留藍牙後備連線與 USB 切換模式後的準備重試。

啟用「自動」偵測後，隨 NVDA 啟動開始尋找裝置。裝置須已開機並連接；實際時間仍受 NVDA 與 Windows 影響。

2.0 錯誤修復版

  • 修正原廠 WinUSB 介面的偵測，保留 Zadig 支援，避免重複嘗試同一介面。
  • 延長切換模式後的 USB 初始化等待時間。
  • 修正不同 NVDA API 目錄結構下的基底驅動初始化與自動連接埠匯入。
  • 提供相符的藍牙 COM 埠供手動連線排錯。
  • 選用 40 方型號前，先拒絕不符的點字方數。

最高宣告測試通過的 NVDA 版本維持 2026.2。

實作已對照 NVDA 2026.2 原始碼；自動化測試涵蓋偵測、傳輸選擇、逾時、資源釋放與安裝包完整性。藍牙實機驗證尚待完成。
