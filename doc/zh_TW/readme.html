QBraille XL USB 與藍牙驅動程式 1.5

讓 NVDA 2026.1 以上版本透過 USB WinUSB 或藍牙序列埠（SPP）連接 HIMS QBraille XL 或相容的 Braille EDGE 點字顯示器。附加元件識別名稱維持 qbrailleXLWinUSB，可直接更新舊版。

功能

  • 自動偵測 USB VID 045E、PID 930B 的 WinUSB 裝置。
  • 自動偵測 Braille EDGE／BrailleEDGE 藍牙 SPP 裝置，不必手動選 COM 埠。
  • 沿用 NVDA HIMS 協定，支援點字輸出、定位鍵、點字輸入與功能鍵。

安裝與自動偵測

  1. 安裝本附加元件並完整重新啟動 NVDA。
  2. 開啟「NVDA 設定 → 點字 → 變更顯示器」，選擇「自動」。若有設定自動偵測裝置範圍，請包含「QBraille XL (WinUSB / Bluetooth)」。
  3. 依下列方式完成 USB 或藍牙連線。NVDA 在背景偵測到裝置並收到回應後會啟用驅動。也可以手動選擇上述驅動，連接埠選「自動」，嘗試目前可用的連線。

藍牙連線

  1. 在 QBraille XL 的 Connectivity（連線）選單選擇 Bluetooth Braille（藍牙點字）進入配對模式；已配對時，選擇這台電腦的點字連線。
  2. 在 Windows 藍牙設定配對「Braille EDGE」。若要求 PIN，原廠手冊指定為 0000。
  3. 確認 Windows 已建立藍牙序列埠（SPP／COM），並保持裝置開機、可連線。NVDA 會自動開啟對應埠。

原廠將「Braille EDGE」用於點字 SPP，「QBrailleXL」用於另一個鍵盤 HID 連線。只配對鍵盤無法提供點字輸出。藍牙不需要 Zadig；若要使用混合鍵盤模式，需另外配對鍵盤。

USB 連線

  1. 使用 Zadig 為 QBraille XL USB 裝置安裝 Microsoft WinUSB。
  2. 將裝置切換至 USB 模式並接上電腦。

疑難排解

  • 確認 NVDA 啟用「自動」偵測，並允許本驅動。
  • 藍牙請確認配對的是 Braille EDGE 點字連線、已有 SPP COM 埠，且裝置選到正確電腦。關閉可能占用相同埠的其他螢幕閱讀器。只有配對紀錄但未開機或沒有回應的裝置不會被當成已連線。
  • NVDA 會在裝置變動時掃描，並在切換應用程式時重試已知的藍牙裝置。若尚未連線，可切換應用程式或重新選擇「自動」。偵測在背景進行；已有其他作用中的顯示器時，遵循 NVDA 原有的顯示器選擇方式。
  • USB 請在裝置管理員確認 WinUSB 驅動與硬體識別碼 VID_045E&PID_930B。
  • 更新後完整重新啟動 NVDA，以釋放舊版持有的連線。
  • 問題仍存在時，開啟 NVDA 偵錯日誌，提供包含 qbrailleXLWinUSB 與連線錯誤的完整日誌。

1.5 更新

  • 加入藍牙 SPP 自動偵測與序列埠傳輸。
  • 未插 USB 時也能使用與偵測本驅動。
  • 連接 NVDA 指定的裝置，連線失敗時釋放埠供後續重試。
  • 更新中英文安裝與排錯說明。
