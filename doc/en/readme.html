QBraille XL USB and Bluetooth 2.0

Connect HIMS QBraille XL or compatible Braille EDGE displays to NVDA 2026.1 or later through USB WinUSB or Bluetooth serial (SPP). The add-on identifier remains qbrailleXLWinUSB for updates.

Features

  • Automatic WinUSB detection for VID_045E&PID_930A and VID_045E&PID_930B.
  • Automatic Bluetooth SPP detection for Braille EDGE / BrailleEDGE devices, without manual COM port selection.
  • Braille output, routing, braille input and function keys using NVDA's HIMS protocol.

Install and enable detection

  1. Install the add-on and fully restart NVDA.
  2. In NVDA Settings → Braille → Change display, select Automatic. If detection is restricted, include QBraille XL (WinUSB / Bluetooth).
  3. Set up USB or Bluetooth below. NVDA's background detection enables the driver when the device is available and responds. You may also select QBraille XL (WinUSB / Bluetooth) with its Automatic port to try available connections.

Bluetooth

  1. Open Connectivity → Bluetooth Braille on QBraille XL to enter pairing mode. For an existing pairing, select this computer's Braille connection.
  2. Pair Braille EDGE in Windows Bluetooth settings. If prompted for a PIN, the manufacturer specifies 0000.
  3. Ensure Windows has created a Bluetooth serial SPP COM port and the display is powered on and available. NVDA opens the port automatically.

Braille EDGE is the braille SPP connection; QBrailleXL is the separate keyboard HID connection. Pairing only the keyboard does not provide braille output. Bluetooth needs no Zadig. Hybrid keyboard operation requires the separate keyboard pairing.

USB

  1. Install Microsoft WinUSB for the QBraille XL USB device using Zadig.
  2. Connect the display in USB mode.

2.0 — Startup delay fix

  • Try connected USB displays before enumerating Bluetooth ports.
  • Try the known vendor WinUSB interface before registry discovery; stop enumeration on success.
  • Skip read waiting when the startup response has already arrived.
  • Preserve Bluetooth fallback and USB mode-switch readiness retries.

Automatic detection begins with NVDA. The display must be powered on and connected; actual timing depends on NVDA and Windows.

2.0 — Bug fixes

  • Fix discovery of the manufacturer's WinUSB interface while retaining Zadig support; avoid duplicate connection attempts.
  • Allow more time for USB initialization after switching modes.
  • Fix base-driver initialization and automatic-port imports across NVDA API layouts.
  • Provide matching Bluetooth COM ports for manual troubleshooting.
  • Reject unexpected cell counts before selecting the 40-cell model.

The highest declared tested NVDA version remains 2026.2.
